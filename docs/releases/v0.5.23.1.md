# v1 mobile input fix

Mobile input fixes for v0.5.23. This is a prerelease for testing on phones.

- Fixed menu taps being cancelled as swipes when no finger position was available.
- Fixed multiple fingers interfering with menu presses and hotbar taps using another finger's position.
- Fixed quick taps not using held server-menu items, held NPC interactions becoming mining, and duplicate entity-use requests.
- Updated the in-game version and APK version to **0.5.23.1**.
- TCPE now uses **com.truancycraft.tcpe**, so it can install alongside Minecraft. The Android downloads keep our Truancy209 signing key.

This installs as a separate app from the old package. Back up worlds/settings before migrating; Android does not automatically move the old app's private data into a new app identifier.

Native touch regression checks passed and both APKs are signed and checked. Physical-phone gameplay still needs testing. The v0.5.23 scan reports apply only to that release's files; these are new prerelease builds.
