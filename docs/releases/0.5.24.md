# TruancyCraftPE 0.5.24 — Native Servers

Same Pocket Edition feel. Our own native server software.

This update adds standalone TCPE hosting and brings native TCPE servers back into the game alongside Java Edition servers.

- Added a headless Linux dedicated server with Survival/Creative world creation, world saving, autosaves, graceful shutdown, restart persistence and console commands.
- Added native TCPE server entries to the shared server list. Choose **Type: TCPE**, enter the address and port, and join directly. Java servers keep their own connection type.
- Added PNG server icons and live native server status on the same port as gameplay: UDP for the game, TCP for the listing. The default hosting port is **25565** for both.
- Fixed the shared RakNet ACK timestamp bug that could crash native connections, and improved peer IDs, connection errors and LAN discovery.
- Blocked local game-mode, difficulty, keep-inventory and tick-speed controls on remote worlds. World administration is denied by default; `/op username` and `/deop username` are console-only. Operators can use the implemented `/time` and `/gamerule` commands.
- Added **TCSMP**, our native Survival server, hosted on the homelab through Chicago with automatic startup after reboots. **45.41.206.239:25566 · Type: TCPE**. MOTD: **Native TruancyCraftPE survival**.
- Updated Android, Linux, the in-game version and the dedicated server to **0.5.24**. Android keeps **com.truancycraft.tcpe** and our **Truancy209** signing key.

**Alpha notes:** native multiplayer login, multiple clients, chunks, movement/chat, block exchange, saving/restart, public routing and operator restrictions passed automated checks. Broader rendered-client and physical-phone testing is ongoing. The legacy protocol still trusts clients in some gameplay paths and usernames are unauthenticated; keep operators limited to trusted testing until authenticated operator identity is implemented. Paper/PocketMine plugins are not supported. Microsoft login is still not working; username-only Java servers remain the supported Java path. The planned 4jcraft weather system is **not included**. These files have not received fresh VirusTotal scans.
