# v2 mobile tap targeting fix

Another mobile input fix for the Java server alpha.

- Keep each short tap and its screen position until the matching Java target result arrives, including after lifting your finger.
- Preserve multiple taps arriving in the same game tick instead of collapsing them into one action.
- Keep the pending tap ray stable while it is being resolved. Render/camera jitter cannot continually invalidate it.
- Dispatch attacks using the authoritative entity ID, including boss parts with no native visual proxy.
- Clear queued input when opening menus or changing worlds; old taps expire instead of firing much later.

Hitbox sizes, reach checks and server cooldown rules are unchanged. The native touch regressions passed; physical-phone gameplay still needs testing. These new builds have not been uploaded for fresh VirusTotal scans.

Both APKs use our Truancy209 signing key, **com.truancycraft.tcpe**, and show **0.5.23.2** in-game. They update the separate TCPE app from 0.5.23.1 and can coexist with Minecraft.
